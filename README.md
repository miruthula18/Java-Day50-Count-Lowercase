# Java Day 50 - Count Lowercase Letters

## Problem
Write a Java program to count the number of lowercase letters
present in a given string.

## Concepts Used
- String
- Scanner
- for loop
- charAt()
- Character.isLowerCase()
- if condition

## Example

Input:
Hello Java World

Output:
Lowercase Letters: 12

## Learning
Learned how to identify and count lowercase letters in a string
using Character.isLowerCase().
